\chapter{Java moderno que muda decisões}
\label{cap:java-moderno}

\proximasaulas

A turma já programa em Java. Este capítulo não é um tour de novidades:
escolhemos só os recursos que mudam como você modela dados, trata casos
e escreve código concorrente. Para cada um, indicamos a versão do JDK em
que ele ficou final, conforme o JEP que o entregou, e mostramos o que o
\texttt{javac} gera, porque o bytecode explica as regras que parecem
arbitrárias (por que o \texttt{switch} lança \texttt{NullPointerException},
por que um \texttt{record} não precisa de Lombok).

Todas as listagens de bytecode desta parte são saída real do
\texttt{javap} do JDK~25 sobre os exemplos de \texttt{examples/}. Se o
\texttt{javap} for novidade, o capítulo~\ref{cap:lendo-bytecode} ensina a
ler essas listagens; volte aqui depois.
